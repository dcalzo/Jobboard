╔════════════════════════════════════════════════════════════════════════════╗
║                      EXEMPLOS DE BLOQUEIO/DESBLOQUEIO                       ║
╚════════════════════════════════════════════════════════════════════════════╝

BLOQUEAR CONTRATANTE:
$ mongo
> use jobboard
> db.contratante.updateOne(
    { email: "fraud@empresa.com" },
    { $set: { emailBloqueado: true } }
  )
resultado: { matchedCount: 1, modifiedCount: 1 }
✓ Contratante bloqueado! Agora não consegue fazer login.

DESBLOQUEAR CONTRATANTE:
$ mongo
> use jobboard
> db.contratante.updateOne(
    { email: "fraud@empresa.com" },
    { $set: { emailBloqueado: false } }
  )
resultado: { matchedCount: 1, modifiedCount: 1 }
✓ Contratante desbloqueado! Pode fazer login novamente.

BLOQUEAR PROFISSIONAL:
$ mongo
> use jobboard
> db.profissional.updateOne(
    { email: "dev@email.com" },
    { $set: { emailBloqueado: true } }
  )

LISTAR TODOS OS BLOQUEADOS:
> db.contratante.find({ emailBloqueado: true }).pretty()
> db.profissional.find({ emailBloqueado: true }).pretty()
